# Power BI Analyst — DIO

Repositório dedicado aos projetos, desafios de código, modelagem de dados e dashboards desenvolvidos durante a formação/bootcamp de **Power BI** da **DIO (Digital Innovation One)**.

## 📊 Sobre o Repositório

Aqui ficam os materiais práticos produzidos ao longo da trilha, cobrindo desde a extração e tratamento de dados até a construção de relatórios interativos e análise orientada a negócios:

- **ETL e Tratamento de Dados:** Limpeza, normalização e transformação de bases no Power Query;
- **Modelagem Dimensional:** Criação de relacionamentos, tabelas fato e dimensão;
- **DAX (Data Analysis Expressions):** Medidas, colunas calculadas, inteligência de tempo e indicadores (KPIs);
- **Visualização:** Dashboards interativos, design orientado ao usuário e insights acionáveis.
